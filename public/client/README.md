# Aset klien

Aset dalam folder ini berasal dari paket Google Drive yang diberikan klien pada 5 November 2026. Seluruh foto yang aman untuk publikasi telah dirotasi, diubah ukurannya, dikonversi ke WebP, dan metadata EXIF tidak diteruskan. Foto yang memperlihatkan paspor, visa, tiket, atau dokumen pribadi dicatat sebagai media privat dan tidak disalin ke folder publik.

Folder `library` berisi hasil impor lengkap yang aman untuk website. Status izin penggunaan publik tetap dicatat di `docs/CONTENT_VERIFICATION.md` dan dapat diubah melalui Pustaka Media CMS.
